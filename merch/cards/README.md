# 🃏 Figure cards (Series 1)

Hang-card packaging for the display figures. `python3 merch/cards/make_cards.py` rebuilds everything from the game data.

* **Size:** 90 x 140 mm trim, with 3 mm bleed on every side (files are 96 x 146 mm, 1134 x 1724 px at 300 DPI).
  Keep important text 4 mm inside the trim.
* **Fronts:** `silvertear03_front.png` (ultra-rare, gold), `blip_front.png` (rare, purple), `trex_front.png`,
  `wendigo_front.png`, `bun_front.png` (regular, night-sky lavender).
* **Back:** `card_back.png`, shared by every figure (checklist, bios, how to redeem the in-game code, where to play).
* **dieline.png:** for the printer: cut line (red), hang slot to punch (red), blister bubble 68 x 66 mm (magenta),
  safe area (green), bleed (blue). It is a guide, not part of the art.
* **cards_preview.png:** all six, trimmed, side by side.
