# Blipville daily wallpapers

403 wallpapers, one for every Blip you can find in the game, each with its name, type and a line from it.
It leaves out the hidden ones.

1. Download `Blipville_wallpapers.zip` and extract it (right-click, Extract All).
2. Double-click `INSTALL.bat` in the extracted folder.

Windows only. It changes your wallpaper to a different Blip every day and starts when you log in.
`UNINSTALL.bat` removes it.
