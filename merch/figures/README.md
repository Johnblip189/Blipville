# 🧸 Blipville figures: Series 1

Posable pixel figures built straight from the game sprites (`python3 make_figures.py` rebuilds them all).

| Figure | Rarity | File |
|---|---|---|
| Silvertear-03 | ⭐⭐⭐ ultra-rare | `silvertear03_figure.stl` |
| Blip | ⭐⭐ rare | `blip_figure.stl` |
| T-Rex | regular | `trex_figure.stl` |
| Wendigo | regular | `wendigo_figure.stl` |
| Bun | regular | `bun_figure.stl` |
| *(6th slot open)* | | |

Extras (not in the series yet): `robo_bear_figure.stl`, `boo_figure.stl`, `spike_figure.stl`.

**Printing:** each STL is one plate (the figure on its back + its two arms). No supports, PLA, 0.2 mm, 3 walls. Press the
arms into the shoulder holes after printing; they turn all the way round and hold any pose. Loose arm: a turn of tape on
the peg. Tight arm: sand the peg a little (or lower `PEG_D` and rebuild).
